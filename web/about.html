关于项目

一个仿 sylar 的 C++ 高性能服务器，核心设计：协程调度 + epoll 事件循环。

架构

  • 日志系统：Logger / Formatter / Appender / 单例管理器，可定制格式与输出地
  • 地址与 Socket：IPv4/IPv6/Unix 封装，非阻塞 + TCP_NODELAY
  • 协程 Task：C++23 std::coroutine，promise_type 状态机（READY / WAITING_IO / FINISHED）
  • 调度器 Scheduler：3 个工作线程 + 任务队列 + 条件变量
  • IOManager：epoll 边缘触发 + tickle 管道 + 协程句柄登记
  • TcpServer / HttpServer：一连接一协程，HTTP 解析 + 路由表 + 静态文件

设计要点

  • 协程不占线程：co_await 挂起后线程立刻处理其他任务
  • 连接数不受线程数限制：1000 连接 = 1000 个挂起的 handleClient 协程
  • 关闭是协作式：信号 → 标志 → iom.stop() → 队列接力收尾 → join
  • 帧句柄生命周期：move-only Task、只在 done() 时 destroy、责任单点转移
